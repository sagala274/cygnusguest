Notifikasi Telegram

Pantau pendaftaran tamu baru dan aktivitas login ke sistem ini langsung dari Telegram. Khusus dapat diakses oleh Administrator.

Langkah Setup Bot Telegram

1. Buka Telegram, cari @BotFather, lalu kirim perintah /newbot.

2. Ikuti instruksinya: beri nama bot (bebas) dan username bot (harus diakhiri kata bot, mis. pussiberal_monitor_bot).

3. BotFather akan memberikan sebuah token (format 123456789:ABC-defGhIJKlmnOPQRstuVWXyz). Salin token ini ke field "Bot Token" di bawah, lalu klik Simpan.

4. Buka chat dengan bot yang baru dibuat (klik link dari BotFather), lalu kirim perintah /start ke bot tersebut.

5. Kembali ke halaman ini dan refresh — tombol "Gunakan Chat Terdeteksi" akan muncul untuk mengisi Chat ID secara otomatis.

6. Klik "Kirim Tes Notifikasi" untuk memastikan semuanya sudah tersambung dengan benar.
